# Империи парусов — браузерная стратегия

Исходный проект игры на базе версии XXIV. GitHub Pages публикует содержимое архива `site.zip`, размещённого в корне репозитория.

## Первая публикация

1. Скачайте подготовленный файл `site.zip` из ChatGPT.
2. На странице репозитория нажмите **Add file → Upload files**, перетащите **сам ZIP как один файл** (`site.zip`) и сохраните в ветку `main`.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions**, найдите `Publish Imperii Parusov` и дождитесь успешного выполнения. Если действие не началось автоматически, запустите его через **Run workflow**.
5. После успешной публикации игра будет доступна по адресу **https://cdadcc.github.io/imperii-parusov/**.

## Обновление

Замените корневой `site.zip` новой версией архива и сохраните изменения. GitHub Actions автоматически распакует содержимое и обновит сайт. Позднее перенесём отдельные исходные файлы непосредственно в репозиторий, чтобы видеть изменения и работать с кодом по частям.

## Архитектура

В архиве находятся `index.html`, `styles.css`, `scripts/game.js`, `scripts/geography.js`, `scripts/artwork.js` и `assets/images/`.

* Игра пока клиентская; серверный мультиплеер не реализован.
* Сохранения браузера привязаны к домену. Для переноса прежней кампании используйте экспорт/импорт JSON.
* География XVII–XVIII веков пока реконструирована приблизительно и требует переработки.
* Репозиторий и опубликованные материалы являются публичными — не храните здесь секреты.
