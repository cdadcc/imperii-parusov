# Империи парусов — версия XXVII

Браузерная стратегия. **Публичная игра:** https://cdadcc.github.io/imperii-parusov/

## Публикация

GitHub Actions проверяет оригинальный исходник XXVII, затем `tools/split_site.py` собирает разделённый сайт в `dist/`:

- `index.html` — стартовая страница (~6 КБ) с индикатором загрузки;
- `styles/game.<hash>.css` — стили;
- `scripts/<module>.<hash>.js` — тематические модули и упорядоченная инициализация;
- `scripts/loader.<hash>.js` — загрузчик карты и игры;
- `data/*.json.gz` — сжатые данные карты (~5,2 МБ суммарно);
- `data/*.json` — запасной формат для браузеров без `DecompressionStream` или при ошибке распаковки;
- `assets/images/` — 248 самостоятельных изображений.

Имена ресурсов включают хеш содержимого: неизменившиеся файлы пригодны для повторного использования из кеша браузера. Код запускается только после загрузки обеих частей географии. Рисунки запрашиваются браузером при использовании соответствующих адресов в интерфейсе. Отдельной ленивой загрузки регионов карты пока нет.

Суммарный несжатый размер HTML, JS, CSS, сжатых данных карты и всех вынесенных изображений — около 7,9 МБ против исходных 20,6 МБ. Это размер файлов, а не замер времени загрузки или обещание конкретного сетевого трафика. JSON-резерв обычно не скачивается. Скорость зависит от браузера, сети и кеша.

Оригинальная XXVII сохраняется в `game-v27/`; SHA-256:
`16f929033c537c2291776316ae392dde94cb2f8c6c059c307dec66099521fbc3`.
Старые `source-parts/` и `site.zip` не участвуют в публикации.

## Следующее улучшение проекта

Игровые функции теперь редактируются в `src/game/`: карта, флот, армия, экономика, исследования, интерфейс и 3D. Сохраняется совместимость с прежним глобальным состоянием; независимые ES-модули и загрузка географии по регионам остаются дальнейшей работой. Работа над этим не должна заменять игровые механики и не должна нарушать экспорт/импорт кампаний.

Игровая география 1700 года по-прежнему требует исторической корректировки. Проект пока не является серверным многопользовательским миром.


## Локальная разработка

Нужен Python 3. Зависимости устанавливать не требуется.

```sh
python3 tools/split_site.py
python3 tests/check_build.py
python3 -m http.server 8000 --directory dist
```

Открыть http://localhost:8000. Сборщик проверяет исходную версию по SHA-256.
Сохранения игры хранятся в браузере: перенос кода в GitHub не переносит кампании между браузерами и адресами.

## Работа над XXVIII

`development/v28.js` — сохранённые незавершённые изменения следующей версии:
выбор флагмана, корабельный провиант, пополнение в порту, прогноз автономности,
слой портов снабжения, исследования и сигнальный модуль.

```sh
python3 tools/build.py --version 28
```

Сборка XXVIII воспроизводит рабочий файл из текущей разработки побайтно.
Это **не выпущенная версия**: игровые проверки XXVIII ещё не завершены.
GitHub Pages продолжает публиковать проверенную XXVII.

`source-parts/` — альтернативная копия исходника; текущий workflow её не использует.


## Проверки

`python3 tests/check_build.py` восстанавливает исходный JavaScript из разделённых данных и изображений, сравнивает его побайтно с XXVII и проверяет CSS и gzip. Это обязательный этап публикации.

Браузерная проверка (при установленном Node.js):

```sh
npm install --no-save playwright
npx playwright install chromium
# В другом терминале запустить сервер dist на порту 8765:
python3 -m http.server 8765 --directory dist
# Затем:
node tests/smoke.cjs
```

Она проверяет загрузку gzip и запасного JSON, запуск кампании, исследования,
суточный ход, сохранение/загрузку, экраны флота, армии, промышленности, изображения
и ширину интерфейса на мобильном экране. Разделённую игру открывать через HTTP,
а не двойным щелчком по HTML. Для автономного одиночного файла остаётся команда
`python3 tools/build.py --output dist/standalone.html`.


## Исходный код и порядок запуска

Рабочий код — `src/game/`, а не собранные файлы `dist/`:

| Файл | Назначение |
| --- | --- |
| `map.js` | Карта, геометрия, выбор провинций и слои |
| `fleet.js` | Флот, морские приказы, контакты и организация |
| `army.js` | Полки, оснащение, боевая сила и подготовка |
| `economy.js` | Производство, ресурсы, торговля и снабжение |
| `research.js` | Исследования и образование |
| `interface.js` | Панели, окна и обновление интерфейса |
| `rendering.js` | 3D, процедурная графика и портреты |
| `core.js` | Общая симуляция, состояние и вспомогательные функции |
| `initialization/00.js` … `08.js` | Данные и последовательные расширения прежних версий |
| `boot.js` | Создание стартового состояния и запуск часов |

`load-order.json` задаёт обязательный порядок. Функции загружаются до инициализации,
`boot.js` — последним. Скрипты скачиваются параллельно, но выполняются в этом порядке.
Это совместимые классические скрипты, разделяющие глобальное состояние; расширения
в `initialization/` пока не полностью перенесены в тематические модули.

Сборщик больше не перегенерирует рабочий код из монолитного архива. Архив XXVII
используется для извлечения проверенных изображений, географии, начальной HTML-разметки
и CSS. Черновая XXVIII по-прежнему хранится отдельно и не включена в публикацию.

### Производительность

Контуры 3399 провинций сохраняются между обновлениями: меняются только отличающиеся
атрибуты. Повторная установка неизменившейся геометрии границ исключена.
3D-геометрия индексируется в кеше, общие вершины проецируются один раз за кадр,
примитивы полностью вне экрана не попадают в сортировку и рисование.
На паузе неизменившаяся сцена не перерисовывается; движение камеры вызывает новый кадр.
Боевые расчёты и ход времени не привязаны к пропуску рисования.

`tests/performance.cjs` сравнивает архивную и модульную версии в одном браузере:
время обновления карты и рисования 3D, точное совпадение пикселей контрольной сцены,
сохранность DOM-узлов провинций, смену владельца, импорт старого сохранения и перерисовку
камеры на паузе. Для запуска сервер `BENCHMARK_ROOT` должен раздавать архив
`empire_of_sails_v27.html` и папку `imperii-parusov/dist/`. Это локальный сравнительный
тест, а не обещание FPS на любом устройстве.

Последний локальный замер (`docs/performance.json`, один браузер, 1280×900, два корабля): медиана обновления карты 30,8 → 19,4 мс; 3D-кадра 80,9 → 75,1 мс. На других устройствах результат будет отличаться.
